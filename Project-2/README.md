🕹️ Rock-Paper-Scissors Game built using Python as part of the CodSoft Internship.

This project allows users to play against the computer with random choices.
It includes proper game logic to determine win, lose, or tie outcomes.
Score tracking is implemented to keep track of multiple rounds.
Users also have the option to play again after each round.

This project helped improve my understanding of Python basics, loops, and conditionals.
